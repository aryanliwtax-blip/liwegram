# Liweeitax V9 deployment

## Render
- Runtime: Node
- Build: `npm install`
- Start: `npm start`
- Health check: `/health`
- `SESSION_SECRET` is generated by `render.yaml`.

The app listens on `0.0.0.0:$PORT`, which is required for a Render web service.

## Verification
Blue verification is stored in the `users.verified` field and shown on posts, profiles and search results. It is not user-editable from the public UI. Admin can manage verification through the admin endpoints.

## Starter posts
The first boot seeds several text posts and three verified community accounts. Existing databases are not overwritten.

## Important production storage note
SQLite and local uploads need persistent storage or an external database/object store for durable production data.

## V11 persistence
For production persistence, set `LIWEETAX_DATA_DIR=/var/data/data` and `LIWEETAX_UPLOADS_DIR=/var/data/uploads` and attach a Render persistent disk at `/var/data`, or migrate to managed Postgres/object storage.
