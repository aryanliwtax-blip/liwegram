# Liweeitax V10 — Mega Unified Build

V10 consolidates the V1–V9 direction into the current codebase and fixes the V9 frontend JavaScript collision that could stop the page script from executing.

## Authentication
- Visible Login and Create an account actions.
- Real modal UI instead of prompt/confirm authentication.
- Login accepts username or @username.
- Case-insensitive usernames.
- Registration validates username and password and confirms password client-side.
- Session regeneration on login/register.
- Logout destroys the session and clears the session cookie.
- Username availability endpoint.

## Social / creator foundation
- Guest feed / Explore / Reels.
- Profiles, follows, private accounts, verified badge.
- Posts with image/video uploads, likes, comments/replies, saves, reposts/reactions, hashtags, views, drafts and stories.
- Notifications, blocks, mutes, reports, chat and chat streaks.
- Collections, settings, themes, PWA/offline shell and offline video storage from previous build.
- Verification request workflow plus admin-oriented verification data.

## Reliability
- `/health` endpoint.
- Render Blueprint with `PORT` compatibility through Node's environment and `healthCheckPath`.
- `SESSION_SECRET` generated by Render instead of being committed.
- Request throttling for write endpoints.
- Duplicate offline wrapper removed.
- View counting is de-duplicated for a short window per user/session.

## Deploy
Build: `npm install`
Start: `npm start`
Health: `/health`

For production, use persistent/external storage for media and a durable database rather than relying on ephemeral local storage.
