# Liweeitax Mega Plus V4

Social network demo with feed, reels, stories, chat, chat streaks, reposts, reactions, hashtags/trending, collections, profile stickers, pinned comments, privacy controls, drafts, notifications, admin stats and mobile UI.

## Upload change
Media uploads no longer have an app-level size or MIME-type restriction. The server still sanitizes stored filenames. Real deployments may impose limits through the hosting platform, reverse proxy, storage provider, browser, or network.

## Run
```bash
npm install
npm start
```
